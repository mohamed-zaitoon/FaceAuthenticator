Face Authenticator

Upgrade real Android face biometrics to BIOMETRIC_STRONG system-wide.
Release build targeting Android 17, powered by Xposed & LSPosed.

System-Wide Hooks Android framework biometric classes instead of app-specific UI code.
Strong Face Unlock Marks real face sensors as strong where the framework exposes a weaker value.
Smart Routing Starts fingerprint first, then requests face after your configured delay.
Keystore Safe Keeps hardware-backed crypto prompts and configured apps on fingerprint only.
